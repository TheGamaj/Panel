راهنمای اتصال

Android
  1. برنامه v2rayNG یا V2Box را نصب کنید.
  2. لینک اشتراک را کپی کنید.
  3. Add Subscription را انتخاب کنید.
  4. لینک را وارد و Update بزنید.
  5. یک سرور را انتخاب و متصل شوید.
iPhone / iPad
  1. V2Box یا Hiddify را از App Store نصب کنید.
  2. لینک اشتراک را کپی کنید.
  3. Profiles را باز کنید.
  4. لینک را اضافه و Update کنید.
  5. پروفایل را فعال کنید.
Windows
  1. Hiddify را از GitHub دانلود کنید.
  2. لینک اشتراک را کپی کنید.
  3. Add Profile را بزنید.
  4. لینک را وارد و Update کنید.
  5. یک کانفیگ را انتخاب و Connect بزنید.
macOS
  1. Hiddify را نصب کنید.
  2. Subscription URL را کپی کنید.
  3. در Profiles اضافه کنید.
  4. Update را بزنید.
  5. کانفیگ را انتخاب و متصل شوید.
